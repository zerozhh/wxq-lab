# 第一百五十三章 · 后排站位——C 位的安全距离计算：多远才算远，多远已经太远

> **读完这章你能**：按射程与功能重新定义「后排」（周瑜和露娜都不是你理解的那个后排）；算出真正的安全距离——它不是格子数，是三本账的合计；理解角落的利弊与双核错位的取舍；给 C 位配上正确的邻居（护卫、光环、充能）；以及为什么后排的安全从来不是站出来的，是「分配」出来的。

---

## 一、先重定义后排：它不是一排，是三种身份

「后排」在多数玩家的脑里是一排格子——最后一排，放脆皮和射手。第 151 章的距离表已经动摇了这个概念：攻击距离 2 的周瑜和海月站进最后一排，等于每回合先走两步再上班。要把后排站位做对，先把它拆成三种身份：

**位置身份的「后」**：处在远离接敌线的格子上，享受「对面走过来需要时间」的安全。这个身份属于射程 4-5 的单位——公孙离（5）、司空震（5）、杨玉环（5）、大乔（4）。他们站得深，不是出于习惯，是因为**他们的射程允许他们一边白嫖距离一边输出**，距离就是他们的护甲。

**功能身份的「C」**：全阵资源（装备、等级、护卫）的主要持有者，死则全阵崩。这个身份跟射程无关——露娜是攻击距离 1 的近战，但魔律之刃 +28.2、贤者之书 +30.2 的 fit-lift 让她成为全游戏资源密度最高的功能核心；她的「后排保护」保护的是她的输出环境，而不是她站的格子。**露娜的正确站位是中排贴侧翼**：既不顶进接敌线，也不缩到无路可退的角落——她的新月突击本来就是「标最远端」的突进技，她需要的是起跳的踏板位置，不是保险箱。

**索敌身份的「靶」**：在对面判定规则眼里的你。最远端、密集区、等级极值、血量极值——你的每个单位在对面技能眼里都有一个靶标值。这个身份完全由你的站位与养成结构决定，和前三排后三排的关系反而不大。

三种身份经常不重合——这是后排站位一切困惑的来源，也是它的解法来源：**分开判断、分别满足**。公孙离三种身份天然重合（射程深、资源高、且要主动管理「不是最远」）；露娜的功能身份重、位置身份居中、靶标身份要靠等级管理去拆（第 158 章）；周瑜的位置身份应该在前（中排），靶标身份要靠间距拆。先给每个单位标好三种身份，再落格子——这是后排站位的第一步，比任何现成阵型都优先。

## 二、安全距离的三本账

「C 位站多远才安全」是个错误的问题，因为安全不是单一变量。真实的「安全账本」有三本，每本各算各的：

**第一本：锁定技能的账。**钟馗抓最远端、露娜标最远端、太乙拉最远端——这一本的安全法则不是「离敌人多远」，是「**不是全场最远**」（第 40 章给公孙离写的规则，全后排通用）。最远端的格子属于饵，你的核心永远比饵近至少一格。这本账算的是「判定不可达」，成本为零——你只需要一个更远的饵。

**第二本：突进单位的账。**阿轲（闪现，登场即技）、孙悟空（闪现）、以及拿到灵泉法杖的任何单位——闪现抹平了距离，你的后排离对面多远都挡不住一次跳跃。这本账的安全法则因此完全不同：**突进的解法是「落点管理」而不是「距离管理」**——你无法阻止阿轲跳进来，但你可以决定她跳进来之后第一秒看见谁（护卫的脸）、站在哪（太乙的嘲讽圈）。第 154 章整章展开，这里立住结论：距离对闪现单位不设防，护卫对闪现单位才设防。

**第三本：行进时间的账。**对面的非闪现近战从接敌线走到你的后排，需要穿过你的整个阵型——这段路上他们会吃控制、吃集火、吃前排的回身。这本账的安全法则才是「站远一点」：**站得越深，非闪现单位的到达时间越长，你的输出白嫖得越多**。公孙离 5 格射程配最后一排站位，理论上对面的近战摸到她之前要吃满她好几轮技能——这是位置身份的价值本源。

三本账合起来的结论值得写成一句话：**距离防走路的人，饵防锁技能的人，护卫防跳跃的人——三本账不能互相替代，你的 C 位三样都要有。**只算一本账的后排，永远死于另外两本。

## 三、角落的利弊与双核错位

角落是后排站位的经典选择，它的利弊比一般讨论的更极端，值得算细账。

**角的收益有三层。**其一，角度收益：第 151 章的方向型技能（大乔的波浪、花木兰的正面扇区）按朝向结算，角落天然避开大部分朝向的直射——你的 C 位在多数进场角度的技能真空里。其二，收缩收益：角落的两条边是「墙」，贴墙站位让护卫的覆盖圈（周围 1 格）以更少的单位形成完整防御——三个护卫可以在角落封住一个完整的半圆，开放地形要四个。其三，钩饵收益：角落深、距离远，天然满足「比饵近」的第一本账。

**角的代价有两层。**其一，**无路可退**：被悟空、阿轲贴进角落的 C 位，是一个被堵在死胡同里的靶子——开放地形的 C 至少能靠走位换时间，角落的 C 的每一秒都在原地挨打。其二，**全阵偏置**：角落站位的阵，另一侧翼天然空虚，对面从空侧绕进来全程无人设防——第 152 章勾引阵的「空侧守门员」就是为这种地形擦屁股的。

**双核错位**是化解角代价的标准解：两个核心放两个不同的角（或一角一中），对面的突进一次只能扑一个点。但这个方案要付自己的账——护卫只能保一个：太乙的复生给最近的一名、近卫荣耀的 1 格只照一个圈、灵泉项链的回蓝只罩一圈。**双核错位的本质是主动放弃「双保」，换成「对面的突进也只能单吃」**——你是用自己的一半风险，换掉对面的全部效率。什么时候值得换：对面突进强而 AOE 弱（点杀阵容）时，错位赚；对面 AOE 强时，错位的两个散点反而给周瑜们省技能，此时双核聚拢配足护卫更优。错位不是默认答案，是函数。

## 四、C 位的邻居：后排站位的一半是「谁站他旁边」

第 151 章的定律二（位置价值与居民价值）在 C 位的邻格上兑现得最密集。C 位的周围 1 格是全阵价值密度最高的空间，每一个邻格都要按「给 C 增益什么」来招聘，而不是按「谁闲着」来安置：

**护卫格**：太乙真人是第一邻居——开团复生给「距离最近的 1 名英雄」，他站 C 位旁边，这个全游戏最强保命词条就焊死在 C 身上；他的嘲讽圈同时是闪现单位的迎宾门。次选是纯坦度或带控制的护卫（铠的完美复生同理，站进圈内复生自动给到）。

**光环格**：近卫荣耀（战斗开始时周围 1 格加双抗、穿戴者双倍）的穿戴者站 C 旁边，C 位的有效坦度直接上台阶；钟馗的左右 1 格牺牲词条同理——把 C 的邻居位给钟馗，等于给 C 挂一层团队词条。注意光环格与护卫格经常是同一个格子：**邻格的招聘标准是「这一格能给 C 叠几层」，叠得越多越优先。**

**充能格**：灵泉项链「自身及周围 1 格友军每秒获得法力值」——它的穿戴者站 C 旁边，就是给 C 的能量轴装了一条充电线。对露娜（40/70）、周瑜（60/100）这类充能慢的核心，充能格的价值在长对局里折算成整轮技能的提前量。杨玉环（0/20，循环技）的阵容反而要检查邻格别浪费在已经满频的单位身上。

反过来，**两个东西不该出现在 C 位的邻格**：一是另一个需要贴身增益的功能核（两个核心抢同一个近卫荣耀圈，等于资源内耗）；二是「看起来肉其实是要出去打的单位」——邻格的职责是常驻，出去打的单位会把护卫圈带出缺口。后排站位的检查动作因此可以收敛成一句：**每回合开战前，看一眼 C 位周围 1 格的三个邻居，逐个问「你给 C 什么」——答不上来的邻居，换掉。**

## 五、后排对射：当双方都是站桩输出时

后排站位还有一个多数攻略不讲的场景：**双方 C 位互不相见、各自站桩，战斗在两条战线同时进行**——前排绞肉，后排对射。对射局里，后排的站位质量直接决定这场「远程军备竞赛」的胜负：

**先手差**：能量轴决定谁的第一轮技能先落地。司空震 50/75 比公孙离 20/80 快整整一段充能——对射局里司空震的技能先结算，他的站位就可以更靠前（用射程吃攻击距离差），把「技能先手」兑换成「血量先手」。杨玉环 0/20 是循环技的极端，她的后排价值在长对局里按次数复利。**对射局站位的第一问永远是：我这边的能量轴跑得赢对面吗？**

**射程差**：5 格打 2 格是完全不同的战争——周瑜在后排对射里是劣势方，他的 2 格射程逼他向前走，而向前就是接敌线。周瑜的正确应对不是站后排（他站不稳），是**利用中排站位把焦土铺在两队之间的缓冲带**，用地形伤害补射程劣势。对射局的阵型从来不是「后排对后排」的镜像，而是「用中排的支点拆对面的后排阵型」。

**角度差**：公孙离的纸伞「朝目标方向」丢出、悬停处持续伤害——对射局的纸伞方向就是她的全部输出几何。站在对面对角线的 C 位（从她出生点看的正方向）吃满伞的全程，斜角站位则只吃路径。对射局的微调因此有一条具体的动作：**开战前把你方远程的站位斜出对面远程的正面延长线**——一格的偏移，换几十秒的输出差。

## 六、后排三问

**问一：我的 C 位应该站第几排？**按三种身份重新回答：位置身份按射程（5 格站最后一排，2 格站中排），功能身份按资源（资源越重越往里），靶标身份按饵（永远比饵近一格）。三问合成一个格子后，再检查那个格子的可达性——它是不是死角（突进堵门风险）、是不是正面延长线（对射风险）。多数阵容的答案落在「倒数第二排偏侧翼」，倒数第一排留给真正的 5 格射程与饵。

**问二：只剩一个护卫时，保 C 还是保前排线？**保 C——这个问题的本质是「C 死了全阵还有什么」。前排队形垮了可以靠核心的装备质量硬翻，C 倒了多数阵容直接失去胜利条件。护卫的默认岗位是 C 位邻格，只有当对面完全没有突进与锁定（三本账一本都不欠）时，护卫才被解放去支援前排线。

**问三：后排被一场 AOE 打残了怎么办？**先查间距再查站位：如果伤害来源是半径型（周瑜），说明你的 C 位进了别人的 2 格半径——散开一格；如果是全场型（司空震），站位无解，转向数值解（护盾、治疗资源优先给 C，杨玉环的清平给血量最低的三人，别让 C 成为全场血量百分比最高的靶——那是杨玉环破阵的判定）。后排站位的全部检查，最后都汇进第 157 章的逐回合流程里执行。

## 七、演算：一个双核局的后排完整方案

把三本账、角落、邻格全部跑进一个具体阵容：你玩三核骨架的变体——露娜（功能核心，近战）+ 公孙离（位置核心，5 格射程）+ 太乙真人（护卫），装备分配为露娜拿魔律之刃、公孙离拿攻速件。

**第一步，标身份。**露娜：功能身份重（装备全池最贵），位置身份中排，靶标身份高（她是全场等级极值的候选人，海月的靶）；公孙离：位置身份深（5 格），功能身份中（攻速件），靶标身份高（远程 C，钟馗最爱）；太乙：护卫，跟着露娜走（她的复生优先级最高——近战 C 死亡风险最大）。

**第二步，落格子。**露娜：中排偏侧翼，前方留给悟空顶；她的右侧一格给太乙（复生+嘲讽两条程序同时生效），左侧给凑数位（她起跳后的回程掩体）。公孙离：最后一排的另一侧翼——双核错位，对面的突进一次只能扑一个点；她的邻格放钟馗（牺牲词条）和一个凑数护卫。最远端固定放饵，且确保饵比公孙离更远离接敌线。

**第三步，过账本。**锁定账：露娜比饵近、公孙离比饵近，两家钟馗的钩都吃饵——过。突进账：太乙的嘲讽圈罩住露娜区，公孙离区靠钟馗+凑数护卫的收缩封角——半过（这个区的护卫密度低于露娜区，承认它，因为攻速件的公孙离换血能力更强）。行进账：两个核心都在深度 2 以上，非闪现近战到达前要穿过全阵——过。

**第四步，留后手。**这套方案的软肋是对面 AOE 强时双错位变靶阵（第三节讲过）——所以预写一条切换线：读到对面两个面积技能时，公孙离向露娜区收拢半场，改「外散内聚」，太乙的位置不动（他的复生只跟主核心）。预写的切换线是站位方案和站位灵感的分界线——**没有备用线的方案，只是运气好的那一种。**

## 八、自测与练习路径

后排站位是全站位篇里「答案最不标准」的一章——前一章的四种阵型可以背，这一章的三本账只能算。所以练习方式也不同：**每局只审一个核心**。第一局只审你的主 C：结算后回答三本账各有没有着落；第二局只审邻格：C 位周围一圈逐格问「给 C 什么」；第三局只审对射：对面远程的位置和你相对的几何关系。三局之后，把三件事并成一分钟的检查流，它就长住了。

两个自测题收尾。**其一**：露娜（近战 C）和公孙离（射程 C）如果只能保一个，太乙站在谁旁边？——按复生优先级答：谁死亡风险大、死亡损失大，保谁；资源分配决定答案，站位只是执行。**其二**：对面没有钟馗、没有露娜、没有阿轲、没有悟空，你的后排还按本章摆吗？——三本账里锁定账和突进账清零，只剩行进账，此时后排可以大幅前压（射程差收益最大化）。这两题的共同点：**答案全部来自读对面，不来自背阵型**——这就是站位工程和站位模板的区别，也是下一章（阿轲）要继续加深的东西。练到后面你会发现，站位能力的上限不在摆格子的手上，在读对面的眼睛里——三本账的输入全部来自「对面有谁」，这就是站位工程最终汇入读场与对手建模的原因，也是站位练习永远要「带着对面练」的道理。

## 附：后排站位的三个快速配方

三本账的完整计算需要时间，决赛圈前的三十秒里可以用三个快速配方替代：

**配方一：一深一中一饵。**任何带双核的阵容，默认答案——5 格射程的进最后一排（深），近战或 2 格核心进中排侧翼（中），全场最远给凑数位（饵）。三个位置各挡一本账（深挡行进、中挡突进有护卫、饵挡锁定），是几乎不出大错的地基阵。它的价值不在精妙，在于每一步都可解释——可解释的站位才可以在复盘中被修正，凭感觉摆的阵连错在哪都说不清。

**配方二：护卫指哪我打哪。**护卫（太乙）的位置先定——他贴谁，谁就是本回合的主核心；其余后排围绕主核心配邻格，次核心自动降级为「可牺牲侧」。这条配方解决的是「资源不够双保时怎么分配」，它的副产品是纪律：你不再摇摆于两个核心之间，每回合的护卫位置就是你的资源声明。

**配方三：最远端每回合点名。**开战前最后一秒，确认全场最远的那个格子是你的饵。这一条成本最低、收益最稳定——它挡住的是 26.50%、25.91%、25.52%、23.92% 四个登顶率前列单位的锁定判定，是全游戏性价比最高的一秒钟。把「点名最远端」变成开战前的呼吸反射，你的后排就少掉一半的「莫名其妙被秒」。

三个配方全部是「完整三本账」的降级近似——先用配方上场，用回放复盘时再补账本。站位能力就是用「低配版先跑起来、复盘时逐帧对答案」的方式长出来的，跟练任何手艺一样。

> **本章可迁移原则**：后排不是一排是三种身份——位置身份（按射程：5 格深站、2 格中排）、功能身份（资源持有者，露娜这样的近战 C 站中排贴侧翼）、索敌身份（在对面判定里的靶标值），分开判断分别满足。安全三本账：距离防走路的人、饵防锁技能的人、护卫防跳跃的人，缺一本死于一处。角落三层收益两层代价，双核错位是主动放弃双保换对面单吃——对面 AOE 强时反而不划算。C 位邻格按「给 C 什么」招聘：太乙的复生、近卫的光环、灵泉的充能一站三叠；答不上「给 C 什么」的邻居，换掉。对射局拼能量轴先手、射程差、纸伞角度。C 位站第几排，永远是三身份合成加可达性检查的答案，不是习惯的答案。

# 第一百六十章 · 极限局的站位模板——超顶级登顶局的站位分析：四个模板与一套终检

> **读完这章你能**：看到 120 局唯一登顶局样本中 12 局深度还原的站位共性；拿到四个可以直接套用的终盘站位模板（附阵型图）与模板选择表；学会决赛圈的终检流程——模板化之后最后该核对的那几件事；理解「模板是起点不是答案」的完整含义。

## 一、样本与方法：从 120 局里凿出 12 局

本篇的站位知识到此全部交付，最后一章给它们一个「成品形态」——直接可以套用的模板。模板的来源是第一卷第 61 章那批 120 局唯一登顶局的样本：从中筛出终局阵容信息最完整的 12 局，做站位的逐回合还原（口径说明：还原基于结算画面的阵容与站位记录，个别回合的微调存在推断成分，清点数字按本次还原口径标注待验证）。为什么是 12 局：样本要同时满足「登顶者全程压制力」「终局阵容构成清晰」「对位对手类型覆盖面广」三个条件，筛完剩 12——数量不大，但每一局都是「打穿了全场的人」的终盘形状，模板价值密度极高。

先给清点出来的五条共性，后面按模板展开：

1. **饵位常设**：12 局的终盘阵里，最远端的格子全部放着非核心单位——没有一个登顶者把核心暴露在最远端。这条与第 49 章的钩饵规则、第 152 章的勾引阵完全互证。
2. **护卫贴身率极高**：12 局里至少 10 局的主核心邻格有复生/嘲讽/光环类单位（太乙真人占大头）——「给 C 什么」的邻格招聘（第 153 章）是登顶局的标配而非选修。
3. **阵型不对称**：超过半数的终盘阵不是左右对称的——保护阵与勾引/外散的组合形态（第 152 章的不对称折中）是决赛圈的常态，完美对称的「教科书阵」反而是少数。
4. **分散度随对手调整**：决赛圈对位 AOE 阵的登顶者，间距明显拉开；对位突进阵的登顶者，明显收缩——没有人用一套间距打完决赛圈。
5. **决赛圈动作变少**：与直觉相反，登顶者的决赛圈站位调整频率低于中期——该做的针对性在中期已完成，决赛圈的动作以微调与轮换为主（第 159 章的混合策略纪律）。

五条共性拼出的印象很一致：**登顶局的站位不是更花哨，是更少犯错**——每一章教过的纪律都能在样本里找到倒影，登顶者的过人之处不是知道更多，是把每一条都执行到了终盘。

## 二、模板一：铁桶护卫阵

适用：单核心资源重装阵容（露娜线为代表），对面突进强。

```
　　　　　敌方
────────────────
　饵　　　　　　　      ← 最远端凑数位
　　　钟馗　前2　　      ← 抵抗线（钟馗光环照前）
　　　　　悟空　　      ← 副核/游走
　　　太乙　C　　　      ← 护卫圈：太乙贴C（复生+嘲讽）
　护2　　　　　　　      ← 侧翼守门
────────────────
　　　　　我方
```

阵眼：太乙与 C 的贴身对（复生词条焊死在 C 身上，嘲讽圈迎击一切落点）；抵抗线与护卫圈之间留一格纵深（让对面的第一波先手打在抵抗线上，护卫圈完好地接第二波）。代价：全阵偏密集，对面 AOE 强时禁用——它是「赌对面突进强于 AOE」的形状。

## 三、模板二：钩饵四分阵

适用：对面锁定技多（钟馗/露娜/太乙密度高），你的阵容机动性中等。

```
　　　　　敌方
────────────────
　饵A　　　　　前1　　
　　　　　　　　　　　
　　　C1　　　　　饵B　  ← 双饵：最远端两端各一
　　　　　　　　　　　
　护　　前2　　　C2　
────────────────
　　　　　我方
```

阵眼：两个饵分布在最远端的两端——对面的锁定技能无论从哪个方向结算，咬到的都是饵；你的两个核心分别藏在两个「次远」的侧翼，中间留空（对面的近战走进空地，就要同时面对两翼的输出）。代价：双饵占两格人口，阵容深度不足时用不起；且对面的行进速度慢于你的收割速度时，空地会变成对面的集结地——它赌的是「你打得快」。

## 四、模板三：分批二梯队阵

适用：对面控制链强（两个以上控制源），你的前排质量高。

```
　　　　　敌方
────────────────
　饵　　前1　前2　　    ← 第一梯队：饵+双前排
　　　　　　　　　　　　
　　　　铠　　　　　     ← 中间层：自带复生的缓冲
　　　　　　　　　　　　
　C　太乙　护2　　　     ← 第二梯队：晚两三秒进场
────────────────
　　　　　我方
```

阵眼：三个梯队的时间差——前排吃掉对面控制链的第一环，铠的复生缓冲第二环，核心梯队在对面的技能真空期进场收割（第 156 章破局一的成品形态）。代价：输出延迟三秒，快攻阵容用不起；且对前排质量要求极高——前排死得太快，梯队就变成添油。它是「赌我的前排能买到三秒」的形状。

## 五、模板四：双核错角阵

适用：双核心阵容，对面突进与 AOE 一强一弱（第 153 章的错位函数取正值时）。

```
　　　　　敌方
────────────────
　饵　　　　　　　前1　
　　　　　　　　　　　
　　　C1　太乙　　　　   ← 角落一：主核+护卫圈
　　　　　　　　　　　　
　　　　　　　C2　　
　护2　　　　　　前2　   ← 角落二：副核独立成点
────────────────
　　　　　我方
```

阵眼：两个核心各占一角，对面的任何单次突进只能扑一个点；每个角内部是小型铁桶（护卫贴身）。中路的空旷是故意的——引对面的近战集群走中路，两角的火力在中路交叉。代价：放弃双保（护卫资源分属两角），对面 AOE 强时两角都是靶——它赌的是「对面打不死我的任何一角」。

## 六、模板选择表与案例还原

四个模板的选择只看两个变量——对面的威胁类型与你的核心结构：

| 你的核心 | 对面突进强 | 对面 AOE 强 | 对面锁定强 |
|---|---|---|---|
| 单核重装 | 铁桶护卫阵 | 铁桶 + 拉开外圈间距 | 钩饵四分阵 |
| 双核 | 双核错角阵 | 双核错角 + 全阵间距加密 | 钩饵四分阵 |
| 前排质量高 | 分批二梯队阵 | 分批 + 前排散点 | 钩饵 + 分批混合 |

**案例还原（节选两局的关键回合）**：其一，三核骨架登顶局，第 17 回合对面剩 AOE 阵——登顶者从铁桶阵切换为「铁桶 + 外圈拉开」（护卫仍贴身，抵抗线后撤一格），代价是接受对面 AOE 多吃一格，换来护卫圈不散——这一步的取舍在第 155 章问一里写过的「护卫保命、核心保间距」完全一致。其二，公孙离保底局，第 18 回合对面是双锁定——登顶者把双饵位的其中一饵换成了带嘲讽的中排单位（饵从「白给」升级成「有去有回」），结算里对面的钩子拉走的那个单位转身嘲讽了拉人者——饵的质量管理（第 152 章饵的排序）在极限局里的高级形态：**饵不只是牺牲位，可以是陷阱位**。

两局还原的共同点：登顶者在决赛圈的每个站位动作都有明确的「对面输入」作为触发——没有一步是凭感觉的形状优化。这正是本篇从第 151 章到第 159 章反复建立的同一个结论在极限局里的样子。

## 七、决赛圈终检：模板摆完之后的最后六项

模板套用不等于万事大吉——摆完模板到开战之前，过一遍终检清单（全部来自前文，这里是集中收口）：

1. **最远端是饵**（第 152 章）——且换人后重新确认过。
2. **核心邻格三叠**（第 153 章）——复生/光环/充能，逐格问「给 C 什么」。
3. **等级极值不是核心**（第 156/158 章）——海月在场时，全场等级最高是谁再核一遍。
4. **间距过对面最大半径**（第 155 章）——决赛圈对手的技能清单再扫一眼。
5. **纵向无三人共线**（第 155 章）——错排半格。
6. **可变位已按混合策略轮换**（第 159 章）——这回合用的是基线还是变体，是随机选的还是被对面诱导的。

六项过完，开战。**终检的总时间应该在三十到六十秒**——决赛圈的时间预算（第 157 章）就是为这六项准备的。每一项都是一个已知的判定漏洞，六项全过意味着你的阵在机制层面无懈可击——剩下的胜负，交给资源、执行与一点点运气，而那已经不是站位能负责的部分了。

## 八、模板三问

**问一：模板和前面八章的「现场推」矛盾吗？**不矛盾——模板是「现场推」的缓存结果。前面八章教你从判定推出对策（慢但通用），模板把高频对局的答案提前算好存起来（快但只覆盖已知局面）。正确的用法：**平时用模板起手，发现现场输入与模板假设不符时，退回推理链现场改**——模板是地图，推理是导航，地图失效时你还有导航。

**问二：模板会过时吗？**会——模板的假设之一是「对面阵容的技能清单」，版本更替会改清单。第 97 章的版本观在这里同样成立：模板的形状会过期，模板的推理（每个格子的理由）不会。所以模板要带着「它为什么长这样」的注释使用——本章给每个模板写了阵眼与赌注，就是在给它们写保质期标签。

**问三：我的分段需要这么细的站位吗？**分段越低，站位纪律的回报越高——因为你的对手犯的站位错误更多，你只要少犯就赚。反过来，本篇的终点（心理博弈、混合策略）在高分段才兑现。**从第 151 章的三问到本章的六项终检，每一层都有它起效的段位区间**——但顺序不变：先把机制学对（低段位通吃），再学对位（中段位拉开差距），最后才轮到博弈（高段位的决胜层）。站位这个免费变量，是你爬每一段阶梯时都最划算的那块砖。

## 九、案例还原（完整版）：一局登顶局的决赛圈站位全程

把节选里的第一局展开成全程，看模板是怎么在实战里被一步步「走」出来的（还原口径同第一节）。

**背景**：登顶者使用三核骨架变体（露娜+悟空+太乙真人+钟馗），决赛圈对手三家：周瑜焦土流、大河图腾成长线、公孙离射手保底流。

**第 14 回合，四强站位的预研。**他维护的威胁简表三行：周瑜（间距纪律）、大河（图腾位当假靶）、公孙离（纵线纪律 + 觉醒攻速的时点压力）。此刻他的阵是标准铁桶——三个对手里两家不构成铁桶的天敌。

**第 15 回合，对周瑜。**切换为铁桶 + 外圈拉开：抵抗线后撤一格，护卫圈不动。结算赢下，掉血可控——间距纪律兑现。

**第 16 回合，对大河。**图腾被对面的站位摆在集火线上，他顺手把自己的饵位微调到图腾的对面——两个「判定磁铁」隔空对峙，对面的范围技先吃图腾，他的凑数位反而安全。这一回合他动的只有一个格子，但这一格是「读懂了对面的站位意图」之后的动作——行为侦察（第 158 章）的收益兑现。

**第 17 回合，对公孙离。**他把阵里唯一的纵线拆掉（错排半格），同时把悟空挪到公孙离的进场角度侧后——大棒的角度管理。这一场是决赛圈最险的一场：公孙离的攻速已经起来，他赢在悟空先手拍掉了对面的前排层。

**第 18 回合，终局对周瑜。**六项终检全过（他专门重新核了间距——周瑜的焦土在上一场又升级了）。模板维持，混合策略的变体随机选了一个核心偏移的变体。终局赢下，登顶。

全程统计：四个对手回合里，他的站位动作合计七格次——平均每场不到两格。极限局的决赛圈，站位的故事不是「摆出了什么惊人阵型」，而是「每一步都刚好是对面输入的正确响应」——**少而准，是站位能力的最终形态**。

## 十、自测三题

**其一**：四个模板都对不上我的阵容（三核以上多核心），怎么办？——组合使用：模板描述的是「功能块的相对位置」，不是单位数——铁桶护卫阵的核心圈可以包两个核心（双 C 贴身），四分阵的两个侧翼各藏一组核心。先拆功能（谁要护卫、谁是饵、谁在抵抗线），再套模板的相对关系，不要按单位数硬搬。

**其二**：模板摆完发现对面这回合换人了（威胁变了），来不及重摆怎么办？——只动两个格子：饵位（最远端重新点名）和护卫贴身方向（跟着最大威胁走）。这两格是所有模板的公共阵眼，动它们能保住八成的模板价值——这也是终检清单前两项放在最前面的原因：**时间不够时，先保公共件。**

**其三**：怎么把本章的模板变成我自己的？——三步：第一步，用本章四个模板打十局，记录每次「模板假设不符」的时刻；第二步，把不符的时刻按「对面什么输入、模板哪个假设」归类，你自己的高频对局形态就浮出来了；第三步，为你最常见的形态定制第五个模板——注释它的阵眼、赌注与失效条件。到第三步完成时，你对模板的态度就会从「照着摆」变成「知道它什么时候不灵」——那才是模板这个东西真正教给你的东西。

## 十一、模板的失败案例：三次典型误用

模板的价值一半在正确使用，一半在看清误用。三次还原中观察到的典型失败（登顶局的对照组——那些差点没走到的局）：

**误用一：拿模板当万能钥匙。**一家铁桶阵从头摆到尾的登顶候补，第 15 回合被周瑜的焦土叠了三层持续伤害——他的模板没有错，错的是模板的适用条件（对面 AOE 强时禁用）从未被核对。铁桶阵对付突进阵是利器，对付面积阵是靶子，**模板的适用条件写在每个模板的「赌注」一行里，跳过赌注直接套形状，等于把保险箱的密码贴在门上**。修正习惯：套模板前先念一遍它的赌注，赌注与对面阵容不符就换或改。

**误用二：决赛圈大改阵。**另一家在第 18 回合（终局前夜）突然放弃摆了三局的阵型，换上一个「针对性更强」的新阵——结算惨败。原因不在新阵的思路（思路是对的），在**新阵没有经过实战验证**：阵眼的配合、护卫圈的落点、饵位的联动，每个细节都要在真实战斗里校准，而决赛圈没有给你校准的回合。第 157 章的「大重排是一次性的」纪律在决赛圈要以更严的形式执行：**终局的阵，必须是已经打过至少一场的阵**——要改，在倒数第二回合改；终局回合只做微调与轮换。

**误用三：把「高手的形状」抄成自己的模板。**还原样本里有一个反复出现的现象：中段位玩家复刻登顶局阵容时，连站位一起复刻——但登顶者的站位是「对他的对手们」的响应，复刻者面对的对手不同，同样的形状就失去了它的全部针对性。第 76 章的选择偏差（别人的条件统计不描述你）在站位端的版本：**别人的模板描述的是别人的对局，你的模板只能从你的对局长出来**。本章第十节自测三给的三步法，就是把「别人的模板」转化成「你的模板」的唯一路径。

三个误用合起来指向同一句话：模板是有前提的结论，模板的边界比模板的形状更值钱。本章给每个模板写「赌注」、给每条共性标「口径」、给每个案例注「还原成分」，这些看似啰嗦的边界标注，恰恰是模板区别于口诀的地方——**口诀告诉你怎么摆，模板告诉你什么时候这套摆法会失灵**。站位工程的终点不是「永远有阵可摆」，是「永远知道自己这套阵的失效条件」——知道失效条件的人，才敢在失效来临时果断地推倒重来。

## 十二、站位篇总收口

十章走完，把整篇压成一张总图。第一层（第 151 章）是机制：距离、索敌、范围、移动、能量——你只能控制判定的输入。第二层（第 152-156 章）是场景：前排四阵型、后排三本账、反刺三方案、AOE 六型、控制链四破局——每个场景都是机制在特定威胁下的应用。第三层（第 157-159 章）是流程与博弈：逐回合的时间线、对手的心理层级——站位从静态的格子变成动态的决策流。第四层（本章）是成品：模板与终检——知识被压缩成可以随身携带的形状。

四层的用法是从后往前长出来的：先背模板（第四层）能立刻上场，出问题回场景层找原因（第二层），场景对不上回机制层重推（第一层），最后把流程养成习惯（第三层）。**站位能力就是在这四层之间反复穿梭的过程中长出来的**——而它全部的成本，只是每回合几秒钟的注意力。这是这个游戏送给所有玩家的最便宜的深度，也是第五篇用十章篇幅想要兑现的那句话：免费的变量，值得最认真的对待。下一篇我们离开格子，进入天赋——那个从第一回合就在影响你的阵容、却又最容易被「跟着感觉选」的系统。第六篇的目标和本篇一样：把感觉换成推理链。

> **本章可迁移原则**：12 局极限局还原的五条共性——饵位常设、护卫贴身率极高、阵型不对称、分散度随对手调整、决赛圈动作反而变少：登顶局的站位不是更花哨，是更少犯错。四个模板按「核心结构 × 对面威胁」选用：铁桶护卫阵（单核对突进，太乙贴 C 是阵眼）、钩饵四分阵（双饵两端，锁定技全场哑火）、分批二梯队阵（前排买三秒，控制链局专用）、双核错角阵（放弃双保换对面单吃）；每个模板都带赌注，赌注错了形状再对也是输。模板是现场推的缓存——起手用模板，假设不符退回推理链；决赛圈六项终检（饵/邻格/极值/间距/纵线/轮换）三十到六十秒过完再开战。从三问到终检，每层纪律有各自的段位区间，但顺序不变：机制、对位、博弈——站位是爬每一段阶梯都最划算的那块砖。

*本章数据来源：120 局唯一登顶局样本与天赋出现率见第 61 章（09-14 快照）；12 局还原的五条共性清点、阵型图与案例节选为本次还原口径的整理，个别回合微调含推断成分，标注待验证；四模板的阵眼与赌注结构为本章给定的操作框架；技能判定与装备文本分别来自 data/hero-details.json 与 data/equipment.json（verified: true）。*

# 第一百五十四章 · 刺客应对——阿轲来切你的露娜怎么办：反刺三方案的完整决策树

> **读完这章你能**：读懂阿轲的完整机制（为什么她不用装备就能切死后排、为什么她随对手血量下降而变强）；理解「切后排」的威胁不止阿轲一人；掌握反刺三方案——反蹲、诱饵、收缩——各自的适用与代价；拿到一张从对面信息推断刺客威胁的判定信号表，以及保命装备与站位的配合方式。

---

## 一、先把阿轲的机制读穿

站位应对的前提是知道对面在算什么。阿轲的卡面文本拆成四行，每一行都指向一个站位动作：

**「闪现」**：她不吃行走时间。第 151 章已经立过结论——距离对闪现单位不设防。你的后排摆得再深，她的落点照样在你身边。这条 tag 宣告了「用距离防阿轲」这条路从头就不存在。

**「登场：自身及随机 1 名英雄等级 +1，棋手生命值每降低 10 点，重复 1 次」**：这是全游戏最独特的成长机制——**阿轲的登场等级和她的主人已掉多少血挂钩**。一个血量健康（80 血）的阿轲玩家，她的阿轲登场时几乎是白板；一个被打到 30 血的玩家，他的阿轲登场时已经凭空吃了 5 层等级（每降 10 点一层）。**这改写了威胁评估的基本盘：刺客的威胁不是恒定的，是随对手血量下降而上升的。**血量最低的那家，他的阿轲可能比你想象的肥两个档次——第 150 章的全场血量结构读法，在这里多了一个专用的列。

**「能量 30/35」**：开场几秒内必技。你没有任何「反应时间」——战斗开始的第一秒，你的后排已经在被计算击杀顺序。

**「弧光：2 次攻击，每次 100% 物理攻击力」**：技能本体不算华丽，她真正的杀器是普攻与连击的衔接，以及——第 64 章讲过的——**百锻刀**。百锻刀是阿轲武器的唯一来源（击杀叠攻击、胜利翻倍，无合成树），它把阿轲从一个「机制刺客」变成一个「滚雪球刺客」：前期杀掉的每个单位都在给她加攻击，连胜玩家的阿轲到第 15 回合可能已经叠出全场最高物理面板。所以评估对面的阿轲要看两条线：**她的主人血量有多低（登场等级）**和**她的主人连胜有多长（百锻刀层数）**。

还有一个数据要说：第 91 章的全池出场率里，阿轲只有 3.3%——全池最低的级别之一。低出场率意味着多数玩家对她的反刺熟练度低，她的击杀效率在实战里高于面板预期。**冷门的刺客比热门的刺客更好杀你**，因为你的肌肉记忆里没有她。

## 二、威胁不止阿轲：三个「会出现在你后排」的人

把反刺写成阿轲专题是常见的窄化。用第 151 章的判定表扫一遍，会在你后排出现的单位至少有三类：

**闪现型**：阿轲、孙悟空、拿到灵泉法杖的任何单位。特点是从天而降，落点在你核心附近。悟空（25.10%）的大棒是前方型 AOE——他切的还附带范围伤害，对收缩阵的反噬比阿轲更狠。

**锁定突进型**：露娜（标最远端，突击期间不可选中）、太乙真人（拉最远端）。他们的目标由你的站位指定——你摆谁在最远端，他们打谁。第 152 章的饵已经覆盖了防御面，这里要补的是反面：**这两位也是可以为你所用的突进**——你的露娜突对面的最远端，和对面阿轲切你的露娜，是同一套机制的两面。

**行进渗透型**：无闪现但移速快、身板能穿过前排缝隙的近战（典型如花木兰轻剑形态的七段连击）。他们的威胁比闪现型低一档，但行进账（第 153 章第三本账）一旦失算——比如你的控制位先手被秒——他们就成了从缺口涌进来的水。

三类威胁的应对核心相同（落点/目标/缺口管理），但侧重点不同：闪现型管落点，锁定型管目标，渗透型管缺口。本章后面以阿轲为主线，方案对所有三类通用。

## 三、反刺三方案

### 方案一：反蹲——让落点变成陷阱

**做法**：在核心的邻格预置控制与复生——太乙真人贴身站（他的嘲讽圈「周围 1 格」就是阿轲的落点覆盖率，开团复生又自动给到 C 位），近卫荣耀的穿戴者站进同一个圈。阿轲闪进来的第一秒，落在嘲讽圈里：她被控住、你的 C 位带着复生词条、近卫的双抗让她打不动——**一次跳跃换来三重反噬**。

**适用**：你有太乙（或同级控制护卫），且对面刺客威胁明确。这是三方案里最稳的一个，也是三核骨架的默认解——太乙真人 25.52% 的登顶率里，相当一部分价值就是「站对位置」这一个动作贡献的。

**代价**：护卫被钉死在 C 位旁边，前排线的强度下降（第 153 章问二的老问题）；且反蹲是**明牌**——全透明机制下对面看得见你的太乙站哪，有经验的刺客玩家会等你的嘲讽圈交在其他方向时再进。所以反蹲要配上假动作（第 159 章）：阵型保持惯性，别每回合都用同一种「明牌反蹲」。

### 方案二：诱饵——给她一个更好的目标

**做法**：在真实核心之外，制造一个「看起来更好杀」的假 C——一个站在后排、装备了廉价输出装或干脆什么都没有的脆皮。阿轲的 AI 不看你的阵容表，她看的是「哪个目标最脆最近」：假 C 越像真 C（站位靠后、模型远程、身板脆），她扑错的概率越高。真核心此时藏在护卫圈里（与方案一的收缩要素合用）。

**适用**：你没有控制型护卫，或者对面刺客太多（两个以上闪现单位）保不过来。诱饵的本质是**用信息不对称对抗数值劣势**——你的护卫不够，但你的假动作免费。

**代价**：假 C 要占一个上阵格（机会成本是第 65 章的一格人口）；且假 C 的说服力依赖你的整体伪装——对面的刺客玩家如果读懂了你（第 177 章的「从站位推断执行水平」逻辑反过来用在你身上），你的饵就是白占的格子。**诱饵方案的天敌是会读人的对手**，低段位好使，高段位要与其他方案混用。

### 方案三：收缩——围角死守

**做法**：核心缩进角落，两到三个单位贴身围成半圆（第 153 章的角落收缩收益：三个护卫封住半圆）。所有突进落点都被迫发生在围圈的外缘，你的集火效率最大化——进来就是被三个单位同时打。

**适用**：没有太乙、没有多余人口放饵的极限局；或者你已经决定「这回合的胜负就押在核心的输出时长上」（保护阵的极端形态）。

**代价**：收缩阵是第 152 章写过的「保护阵天敌」的完全体——**对 AOE 零抵抗**。悟空带着大棒跳进来，你的半圆就是他的圆心；周瑜一个圆罩住全家。收缩是「赌对面只有单体伤害」的阵，赌错就是团灭。所以收缩方案有一个硬前置：**确认对面的面积技能与突进不会同回合生效**，否则改用方案一。

## 四、判定信号：这局我该防刺客吗

三方案怎么选，取决于威胁等级。从每回合的公开信息里推断刺客威胁，四个信号按优先级排：

| 信号 | 观察点 | 威胁读数 |
|---|---|---|
| 血量结构 | 对手血量低于 50 且持阿轲线 | 登场等级高——高威胁，方案一立即上线 |
| 连胜结构 | 对手 5 连胜以上且镜线（百锻刀渠道） | 刀已开始叠——中高威胁，中排开始留护卫 |
| 闪现密度 | 对面阵容里闪现 tag 单位数量 | 两个以上——落点管理优先，评估收缩风险 |
| 装备信号 | 对手散件合成指向暴击/攻速系 | 物理爆发成装在途——按已成型对待 |

四个信号的合成规则：**任意两个亮灯，按高威胁处理**。反刺站位有一个不对称性必须记住：**防错的代价远小于不防的代价**——多摆一个护卫损失半格战力，少防一次刺客丢的是整场。所以信号模糊时默认防，这是站位版的「方差即成本」。

## 五、装备与站位的配合

站位防不了的部分，交给装备；装备覆盖不到的窗口，交给站位。反刺场景下的配合要点：

**保命装的站位含义**：名刀·司命一类的免死/减伤件，价值在「被切后的第一秒」——它的穿戴者可以站得相对暴露一些，替全阵吸收跳跃目标。**小鹿的庇护（30% 伤害转移，瑶妹巨型玩偶附带）是站位型的装备**：伤害转移的穿戴者应该站在核心旁边——他站哪，哪一格就成了「伤害的漏斗」，漏斗的位置本身就是站位决策。

**真核与假靶的装备区分**：诱饵方案里，假 C 给一两件便宜的输出散件提升说服力（成本约等于两件散件的临时占用，第 59 章的单向门要算清楚——**散件可以后拆，成装不要喂假 C**）。真核心的成装照常配，但站位上享受方案一的完整护卫。

**反伤/反弹类的取舍**：反弹伤害类装备对高攻速刺客（阿轲的连击）有额外的惩罚效果，穿戴者放 C 位邻格当「刺猬护卫」，是没抽到太乙时的替代解——效果不如嘲讽，但方向相同：让落点变贵。

## 六、反刺三问

**问一：对面阿轲一直没亮出来，我防不防？**按信号表处理：血量与连胜结构是先于「亮牌」存在的——阿轲 3 阶、商店可刷，她随时可以从那家血量 30 的玩家手里登场。低出场率不等于低概率，等于**低可见度**。所以信号的观察对象是「谁的血量结构养得起阿轲」，不是「谁的场上有没有阿轲」。

**问二：我的露娜自己就是突进，她算刺客还是算被切的？**都是——这是近战 C 的双重身份。对你而言她是主 C（享受反刺保护），对对面而言她是最远端判定器（享受饵的安排）。站位上她要同时满足两套逻辑：作为被保护者，她比饵近、有护卫；作为突进者，她需要有起跳踏板（中排侧翼，第 153 章已定）。双重身份不冲突，冲突的是「把她摆进后排深处的直觉」——近战 C 永远不要站进后排，那里既不是她的位置也不是她的战场。

**问三：收缩阵被 AOE 打爆了一次，下一回合怎么办？**这就是血量触发判据（第 152 章）：「莫名其妙的血」连续两场，先怀疑阵型。收缩改反蹲——护卫从围圈改成贴身（覆盖面积换覆盖质量），同时把 C 位的站位从死角挪到半开放格（留出被贴脸时的走位余地）。站位方案的全部调整都遵循同一个循环：读伤害来源 → 判定类型 → 换方案 → 下一场验证——**站位没有一次成型的方案，只有收敛得快的方案**。

## 七、演算：一个反刺局的完整回合

把三方案与信号表串成一个真实回合的决策流。第 13 回合，结算画面：你的血量 62，对面四家存活，其中血量最低的一家 34 血，他的场上出现了一张阿轲（此前未见），另一家 6 连胜且你确认他走了镜线（百锻刀渠道）。

**第一秒，过信号表。**血量信号：34 血玩家持阿轲——他的阿轲登场时吃掉约 5 层等级，高威胁；连胜信号：6 连胜镜线——百锻刀在叠，中高威胁。两个灯亮，按高威胁处理，本回合站位按「对面必然有人切你后排」执行。

**第二分钟，选方案。**你有太乙（本局骨架带他）——方案一反蹲上线：太乙贴主核心，复生词条落 C，嘲讽圈迎宾。同时因为对面有两个来源的威胁（阿轲 + 百锻刀持有者的突进单位），你加半层诱饵：凑数位保持在最远端（饵对付锁定技），不动。收缩不用——你的骨架里悟空已经贴脸输出，收缩会挤压他的进场空间，且无法确认对面的面积技。

**开战前最后一秒，点名。**最远端是饵吗？是。核心的邻居给 C 什么？太乙给复生+嘲讽，近卫给双抗——三叠。落点假设？阿轲大概率扑 C，落点在太乙的圈里——方案成立。

**结算后复盘格。**这场的实际伤害来源记录三条：阿轲进了谁的圈、百锻刀单位打了谁、有没有面积技漏防。三条记录进你的对局笔记（data/matches/ 的站位字段），两局之后它们会变成你个人数据库里的「这家玩家的刺客习惯」——第 171 章对手行为数据库的原材料，从这里就开始攒了。

这个回合流可以压缩成一个可背的口诀：**一秒过信号，一分选方案，开战前提名，结算后记档**——四步合计不到两分钟，却把本章的全部内容跑成了闭环。站位工程的所有章节都遵循这个「决策流优先于知识量」的结构：你知道多少不重要，你在开战前的两分钟里按什么顺序执行才重要。

## 八、反刺自测三题

**其一**：你的太乙在下回合的战斗里必须去前排补位（前排缺人），阿轲威胁仍在，C 位怎么办？——降级到方案二加半层收缩：没有嘲讽圈，就给 C 制造假靶与角落，同时接受「这回合的 C 位风险升高」，把风险记进下一回合的资源优先级（也许这回合该买护卫而不是输出）。

**其二**：对面没有任何刺客信号，但你的 C 位连续两场先死——刺客警报是假的吗？——假警报也是警报：C 连续先死说明有某条判定在稳定地选中他（可能是最远端没设饵、可能是血量极值、可能是对面的渗透型单位）。信号表是按「对面的构成」设计的，伤害来源是按「实际发生」记录的——两者不一致时，信实际发生的。

**其三**：你同时被两家刺客盯上，护卫只有一份，保谁？——回到威胁读数：谁的威胁读数高保谁（血量低的阿轲肥于连胜的刀），另一个方向的落点用诱饵顶。护卫的分配原则和第 153 章问二同源：**护卫永远跟着「死亡损失最大且死亡风险最高」的核心走**，其余方向承认风险、用免费手段（饵、假动作）对冲。

## 九、召唤物与牺牲词缀：反刺的隐藏工具箱

卡牌库里有一族效果经常被当成「输出词缀」，它们在反刺场景里的价值其实排在前面——因为它们提供的全是**额外的身体**。刺客的算法定价于「落点处的抵抗密度」，每一个额外身体都在改写这个密度：

**熊灵与召唤位**：熊魂附甲（穿戴 2 件装备的大河英雄阵亡时召唤同等级熊灵）、荆棘牢笼（先知图腾每 5 秒眩晕最远的敌人，眩晕期间阵亡则召唤同等级熊灵）——熊灵出现的位置天然靠近战斗发生的区域，也就是刺客的落点区。一只熊灵等于一个不占人口格的临时护卫：它不输出，但它站住了落点、吃了连击、喂了时间。带图腾体系的局（大河流域），反刺的默认答案里应该有「让图腾与熊灵的落点靠近核心」这一条。

**牺牲词缀的第二用途**：四海来援（无阵营英雄的牺牲：召唤一名同品阶同等级的无效果英雄参战）、怒涛（大乔灵体现身）、自我奉献（河洛牺牲）——牺牲触发的召唤物同样会出现在触发者的位置附近。把「会召唤的单位」摆在核心的外侧邻格，他们的死亡就变成一次「原地补兵」：刺客杀掉的是他，出现的是替身，落点处的抵抗密度没有下降。**牺牲单位是反刺站位里的「可消耗墙」**——比凑数位强，因为他们的死亡本身有产出。

**钩饵词缀与刺客的组合拳**：荆棘牢笼的「每 5 秒眩晕最远的敌人」和熊灵召唤，本质上把「最远端」变成了对面的禁区——刺客玩家读到你带这个词条，他的落点选择会整个后移。站位工程与天赋的联动（第六篇的主题）在反刺场景里最密集：**你的天赋选择本身就是站位资源**，摆阵之前先看一眼自己的天赋栏里有没有额外的身体和额外的控制，这一眼经常改变方案的选择。

工具箱说完了，给一个综合的优先序：反刺资源的配置顺序是**嘲讽/复生类护卫 > 召唤物落点 > 保命装 > 假 C**——前三者是「让落点变贵」，最后一个是「让落点偏移」，前者确定性高，后者依赖对手误读。资源有限时，永远先买确定性。
